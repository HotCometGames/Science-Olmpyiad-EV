# Science-Olmpyiad-EV
Code used for our second place electrical vehicle

This code was created beginning of my junior year in 2025 because a friend had the mechanical vehicle, but needed software to control it. He asked for help, and we spent a couple weeks going over to his house and testing the distances it would go with different floor types, wheel and battery freshness, and power amount. 

This was created before I was fully comfortable with unity and version control, and it was such a small project I didn’t think much of it.

Hope you enjoy it! (for any members of the MIT Engineering Advisory Board reviewing my maker portfolio–hi!)
